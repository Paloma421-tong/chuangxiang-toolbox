# GitHub Pages 镜像

Pages 地址：https://paloma421-tong.github.io/chuangxiang-toolbox/

此站从仓库 `main` 分支的 `site/dist/` 发布。工作流 `.github/workflows/pages.yml` 将该目录作为静态文件制品上传并部署，不执行构建。新增与更新 `site/dist/` 内容后会自动部署，也可从 Actions 手动运行。

GitHub Free 账户要求 Pages 来源仓库公开，因此本仓库源码公开可见。页面与源代码均对互联网开放。Pages 仅为原 Sites 主站的访问镜像；原 Sites 项目和访问设置由 Sites 独立管理，不会随 GitHub Pages 的部署而更新。

页面使用相对路径加载 `assets/fieldwork/` 中的工作簿及预览图，适用于仓库项目站点路径。浏览器收藏保存在本地。部分资源预览会请求 `image.thum.io` 第三方截图服务。

最后更新：2026-10-22。
